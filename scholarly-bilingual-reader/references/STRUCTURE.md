# Reading document format

article.json is UTF-8 JSON with title (string), authors (string), source (string, DOI or other identifier), coverage (string describing accessible material and omissions), sections (array), overview (string), and references (array of strings). Each section has title and paragraphs; each paragraph has id (unique), page (string), en, zh, function, logic, analysis (strings), and highlights (array of objects with start, end, kind). Offsets count Unicode code points, end exclusive. Kinds: claim, concept, evidence, caveat, method. Use exact source text only where authorized; explicitly document omitted or unavailable material. Optional figures array entries have caption, alt, src (authorized embedded raster data URI), page. Never invent figures, references or text. Keep source order and distinguish translation from interpretation.
