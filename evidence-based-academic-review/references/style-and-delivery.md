# 论证结构、文风及交付模板

## 全文布局

| 章节 | 核心科学问题 | 拟用证据 | 可成立的分观点 | 下一节如何承接 | 目标篇幅 |
|---|---|---|---|---|---|
| 引言（后写） | 为什么值得讨论 | 背景文献 | 提出范围 | 引出第一节 | 按需 |
| 主体1…n | 每节一个问题 | 对应研究 | 依据证据形成 | 内容衔接 | 按需 |
| 总结与展望 | 这些研究共同说明什么 | 复用前文证据 | 总观点、局限与展望 | 首尾呼应 | 按需 |

对于约3000字课程论文，可用摘要约200–250字、引言约300字、主体四节合计约2100字、总结约300字为起点；按材料和实际计数调整，参考文献是否计入由课程要求决定。图表与解释是否置入正文取决于用户要求；不要将审校表混入正式论文。

## 审核与逐节确认

框架完成后先交付完整章节表、主线、分观点、证据分配及目标篇幅，明确询问是否修改并停止。未获得明确确认不得写第一节。每轮仅交付一节；正文、证据对应表、参考文献与未核实项分开显示。末尾明确询问是否需要修订、是否确认本节，待回复后继续。若有修改意见，提交修订后的完整章节并再次确认。所有主体章节通过后才进入总结及后写引言、摘要等环节；各新章节仍需确认。保留已确认版本，实质修改重新审核。全文交付目标不等于授权跳过审核节点。仅用户明确取消指定节点时可例外，并记录。

## 段落内的论证

一段通常围绕一个事实或论点；主题句引入需求或已有认识，接着介绍代表性文献的研究设计与结论，必要时与其他研究比较，最后给出由证据支撑的解释、限制或承接下一段。五个步骤不必每段齐全，也不按固定句式填充。

示例（抽象写作模式，不是实证文献）：

- 模板式：“在临床评价方面，某研究……在标准化方面，另一研究……”
- 内容驱动：“早期临床研究主要评价安全性和初步疗效。能否获得稳定的临床获益，仍取决于后续对照研究的结果。”
- 模板式：“此外，……具有重要价值。”
- 内容驱动：“不同研究的评价终点并不相同，因此其效应量不能直接比较。”
- 模板式：“上述研究进一步提供了新的研究思路。”
- 内容驱动：“这些证据将方法学可行性与临床有效性区分开来，也说明两者需要不同类型的验证。”

这些句式仅说明衔接方法，实际使用时必须由具体证据支撑；不自动生成不存在的研究、数据或引用。

## 全文定稿清单

- [ ] 标题、引言、章节主题和总结回答同一核心问题。
- [ ] 每节有自己的分观点且没有重复上一节结论。
- [ ] 文献比较针对可比对象；不同研究设计和证据层次明确区分。
- [ ] 事实能追溯；综合观点不冒充原文结论；无新增未核实数据。
- [ ] 句间和段间由研究内容自然承接；删除空洞套话和过渡句。
- [ ] 专业术语、缩写首次释义、标点和数值格式统一。
- [ ] 文内编号按引言之后的首次实际出现顺序排列，所有编号有文末条目且无多余未引文献；无错误范围或重复编号。
- [ ] 文末书目格式与用户指定标准的版本一致；有必要的更正记录。
- [ ] 区分汉字数、含标点字符数与软件字数；实际测量后才声称满足字数要求。
- [ ] Agent 最终交付另有可下载逐段原文对照核查文件；终稿段落、论断、引用编号、实际来源短引或证据释义、中文释义、真实定位、核查深度和匹配评价一一对应；参考文献均附可点击的已核实入口，无法核实项明确标注。
- [ ] 独立说明未完成的全文核查、付费访问、来源缺失、筛选例外或其他阻碍。

## 输出方式

分节模式：章节正文 → 紧凑核查表 → 新增/复用参考文献 → 未决事项；末尾给出下一节衔接方向，并明确等待用户确认；不得提前写下一节正文。外部反馈模式：关键修改判断 → 完整修订段落 → 必要的引用或编号变化。统稿模式：完整论文（标题、摘要、关键词、引言、正文、结论、参考文献）→ 简短变更说明及未解决事项。默认只给一个主稿；用户要求文件时按可用能力生成实际文件，不声称已保存到外部软件。


## Agent 最终交付文件

默认同时交付正式综述稿（按用户指定格式）、独立的逐段引用原文对照与证据核查文件（优先 `citation-evidence-audit.html`，自包含、可检索；也可按用户指定输出 DOCX 或 Markdown），以及可编辑配图源文件（若有）。核查文件不是论文正文的一部分，样式为按章节排列的正文段落与原始证据对应视图、核查状态、可点击书目及未决项。HTML 仅使用安全本地样式与内容，避免外部依赖，转义原文文本及限制外部链接为安全的 HTTPS 入口；离线浏览不意味着外部全文可离线访问。无文件能力时明确提供结构化替代。按 `evidence-audit.md` 执行，遵守版权与安全规则，逐段验证版本和引用一致性；不把未读全文标为全文核查。
