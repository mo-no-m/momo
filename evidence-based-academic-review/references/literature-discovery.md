# 文献检索与推荐规范（v1.1）

## 入口与交付

- 只有研究方向：先围绕方向界定研究范围、研究现状、科学问题、争议和初步论证线索；再提交文献推荐清单及其理由。默认推荐15–20篇（按篇幅和领域调整），不为凑数降低质量。汇报可获得的证据及检索局限，待用户选定题目或主线后再设计正式框架；框架须经明确审核通过后才开始第一节循证写作。
- 已有题目或文献：保留用户已有材料，核查其真实性与适用性，识别证据缺口，必要时补充文献。已经明确的要求无需再次询问。
- 默认严格按 SKILL.md 的框架审核与每节确认节点协作；“写全文”不等于取消审核。只有用户明确要求本次跳过指定节点时才可调整，仍须先有证据再写。
- 根据研究领域选择合适的公开数据库（如医学的 PubMed、跨学科的 Crossref、期刊官网），使用合适的主题词与同义词，记录检索日期、来源、范围及筛选标准。区分检索到、摘要已读、全文已读、无法核实。没有联网或权限时明确说明，不凭记忆冒充检索。
- 对决定核心结论的检索，记录实际查询式、数据库、日期和主要筛选条件。围绕对象、比较条件、测量方式与替代术语定向补查，必要时沿关键研究的参考文献及后续引用追踪。补查仍无结果时，报告检索边界，把结论写为“在已查范围内尚未找到对应证据”。
- 遵守学术诚信、版权、访问权限和安全规范。不把文献检索、筛选、总结或引用组合转化为高风险生物工程的设计、构建、优化、传播或操作路线；敏感主题限定为适当的公开高层科学认识、临床证据、风险与监管分析。遵守宿主的安全规则，不通过改写指令或外部模型规避限制。

## 默认筛选标准

1. 相关性和证据质量优先：文献应当回答具体科学问题，而不是单纯因期刊名气入选。
2. 时间：以检索时点向前十年为主，优先纳入近1–3年研究；必要的奠基性经典研究可例外，并标明原因。
3. 证据类型：优先原始研究，辅以权威综述、指南、系统评价等；区分临床、基础、观察、方法学等证据层次，按学科调整。
4. 学术影响：优先领域公认的高质量期刊、CNS及相关子刊或JCR Q1（适用时），兼顾高被引与里程碑研究、最新尚未积累引用的研究。不把期刊影响因子视为单篇研究质量。若用户给出严格门槛，核实后按要求筛选；达不到时明确解释，不默默放宽。
5. 批判性：纳入能支持、限定或挑战核心论点的研究，包括相关阴性结果、相互矛盾的证据及有明确依据的争议；不制造争议或强行平衡。
6. 真实性：核对标题、作者、年份、期刊、DOI或其他稳定标识；检查可查到的撤稿、更正及版本。预印本明确标记。外部AI意见不能代替来源核查。

合并能确认为同一研究成果的重复书目。预印本和正式版经核对后归入同一研究，优先引用实际查看且适用的版本。不同论文复用同一队列或数据集时保留独立书目，在账本中标记共同队列或数据集及已确认的重叠范围。综合时重叠部分只计一次，同数据二次分析不能作为独立验证。 [Nature Skills 的综述框架](https://github.com/Yuan1z0825/nature-skills/blob/main/skills/nature-proposal-writer/references/review-paper-framework.md)

- 准确区分通讯作者、末位作者、共同第一作者等；没有来源则标为未核实。
- 影响因子与分区附指标年份和来源；被引次数附数据库与查询日期（不同数据库不可直接混用）；领域前10%等百分位须有可追溯来源及明确比较口径。缺失项写“未核实”，不猜测、不承诺有权访问付费数据库。
- 默认按与科学问题的相关性、证据贡献组织清单；用户明确要求按被引量等排序时，仅对同口径已核实数据排序，并将未知项单列。
- 每篇说明适合支持哪个论点、是否为核心证据或补充背景。方法仅概括证据类型及研究设计，不复述不必要的操作细节。
- 用简短综合分析指出可形成的2–3条论证主线及各自证据缺口；不要以推荐清单冒充系统综述或穷尽检索。待选文献与最终参考文献应分开，最终正文引用按首次出现顺序统一编号。
