# momo · Academic Research Skills

A reusable skill for evidence-based academic review writing.

- [Evidence-Based Academic Review](evidence-based-academic-review/SKILL.md): v1.6: research direction exploration, literature discovery, evidence-first review planning, section drafting, citation auditing, revision, and editable scientific illustrations. See the [literature discovery guide](evidence-based-academic-review/references/literature-discovery.md) and [editable scientific illustration guidelines](evidence-based-academic-review/references/scientific-illustration.md). Includes a [19-palette scientific color library](evidence-based-academic-review/references/color-palettes.md) and visual palette selection before drawing. SVG and native-shape PPTX are preferred; local software use depends on actual tool access and permissions.

**v1.4 approval gates:** present the complete outline and wait for explicit approval before drafting. Draft and audit one section at a time; request approval and stop after each section. Apply revisions and request approval again before advancing. Only finalize after the relevant approvals; a general request for a full review does not waive these gates.

**v1.5 final evidence audit:** Agents with file-generation capabilities must also deliver a separate downloadable paragraph-by-paragraph citation evidence comparison file (standalone HTML by default). Map each final paragraph and cited claim to verified source links, permitted brief evidence excerpts or clearly labeled paraphrases, Chinese explanations, actual source locations, access depth, and support status. Clearly disclose inaccessible evidence; do not invent quotes or links. See [evidence audit guidelines](evidence-based-academic-review/references/evidence-audit.md).

**v1.6 clean manuscript delivery:** The manuscript contains only the complete review, normal in-text citations, approved academic figures/tables where applicable, and the formatted bibliography. Do not add clickable source links or audit materials to the manuscript. DOI/URL fields required by the citation style remain plain text. Place clickable verification links, evidence comparisons, audit notes and unresolved items in the separate audit file.

Download the repository ZIP and copy the desired skill directory into a compatible client's skill location, such as a Codex project's `.agents/skills/`. Client capabilities and source access vary.


Scripts do not replace source verification or domain expertise. Respect academic integrity, copyright, privacy, ethics and safety. No license has been specified.
